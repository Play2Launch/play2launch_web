# 用户视图与演示控制

默认隐藏顶部演示控制按钮，保留 `TEST DATA · NO REAL TOKENS`。不会因隐藏工具而将样例榜单、认证或发行状态表现为真实数据。

进入个人页 `/profile`，展开 `Prototype settings`，开启 `Enable demo controls`，即可使用顶部控制台。可切换活动阶段、模拟 KOL 审核、关闭计分或模拟受邀玩家。

关闭开关立即移除已打开的控制台，但不修改账号、队伍、审核结果、成绩或发行预览状态。开关存于 sessionStorage，在当前标签页刷新和导航后保留；不是账号权限或生产安全边界。live 登录模式不会显示此开关或控制台。

活动及结算页的长篇计分说明移入原生 details，支持键盘展开。有效成绩、计分状态及截止时间不折叠。活动截止后队伍按钮明确显示 Joining closed；其他已有队伍、未认证、待审核等限制继续保留。

本地演示不等于正式后台；生产授权仍必须逐请求在服务器端校验。
