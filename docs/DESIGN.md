# P2L 视觉原型 V0.1

视觉方向：现代 Web3 Launchpad + 社区赛事。以项目发现、可玩内容和共同解锁为核心。

## 视觉语言

- 主背景 `#0b0d0b`，面板 `#141713`，强调色 `#d2fa69`。
- DM Sans 用于业务文字；Barlow Condensed 用于 PAPERHOOD 游戏标题和成绩数字。Google Fonts 暂为外部资源，离线时回退到系统 sans-serif；正式发布建议自托管字体。
- 细边框、低对比层次、有限的径向光晕；强交互用荧光黄绿色，避免所有信息都高亮。
- 平台卡片、导航、状态标签与进度条一致；Campaign 允许独立主题色和主视觉。
- 图片主视觉由内置 imagegen 生成，其他示例项目以排版式字母图形展示，未虚构额外角色图。
- 原型数据有全局标签；登录、成绩和交易边界在相应操作处说明。

## 按钮规范

- 普通操作按钮必须使用 `.btn` 加一个明确的级别类：`.btn-primary` 或 `.btn-secondary`。不要只写 `.btn`，也不要引用未定义的按钮级别。
- Primary 用荧光绿底和深色字，表示当前操作区最重要的下一步；同一操作区原则上只保留一个。Normal 使用 `.btn-secondary`，为深色底、浅色字、细边框，用于取消、查看、刷新和其他辅助操作。
- 两级按钮默认最小高度 44px、圆角 6px、字号 14px、字重 700；密集列表和手机页头允许局部缩至 40px、字号 12px，但同组按钮尺寸须一致。键盘聚焦保留明显的绿色描边。
- Disabled 是两级按钮的状态，不是第三种级别。不可点击，保留原尺寸和文案，使用中性灰绿色，且不出现 hover 上浮或变亮；异步操作可将文案改为“处理中…”并设置 `disabled`。链接若需不可用，不应只靠视觉上的 `aria-disabled`，还必须阻止导航。
- 纯文字链接、筛选标签、图标操作和游戏内交易按钮是独立控件，不强制套用普通操作按钮的外观；但其禁用和键盘聚焦状态仍须清楚。

## 页面

- Discover：首屏展示 Genesis 主 Campaign 和即时参与入口，下面为可筛选项目列表及社区排行。
- Campaign：Overview、Teams、Leaderboard 共用面包屑、导航 tab 和紧凑活动头卡，顺序固定为面包屑 → tab → 头卡 → 页面内容；桌面内容区双列（项目故事 / 解锁面板），手机先展示参与入口，再展示战队和玩法说明。页面专属人数、排行和操作放在头卡下方，不另造活动身份卡。
- Game：可实时操作的价格曲线和大面积单手按钮，桌面有角色提示区，手机纵向排列。
- Result：突出本次成绩、重玩、保存、战队和分享；不编造真实排名百分位。
- Teams：可搜索列表和战队详情；邀请来源与加入状态分开。
- Leaderboard：前三名与数据表；种子用户与有效模拟提交统一计算，明确标记 Demo。练习成绩不混入有效模拟榜单。
- Launch：四阶段预览。倒计时结束不会自行宣称链上成功。
- Profile：本地历史、身份状态和未来钱包接入位置。

## 后续

沿用现有设计 token 和组件维护玩家与 KOL 队长端。当前活动仅由平台管理后台创建和发布，不开放 Creator 功能。真实数据接入后，再调整字段、人数目标、分发与交易能力；不需要重新制作整套静态设计稿。
