# Competition rules · V0.2 demo

本版以本地测试数据跑通规则，不接后台、不产生真实奖励。页面内的 demo standings 是可联动的模拟榜单，不是经过验签的正式榜单。

- 同一用户每个活动只加入一个队伍，首次加入后不能换队。不同活动独立选择。邀请来源不自动等于队伍归属。
- 一局完整 30 秒游戏且至少完成一笔交易才是有效轮次；0 分仍可有效。退出或零交易不计有效参与。
- 登录后点击 Save score 提交；游客可以在结算页登录补交。提交时必须早于该活动的截止时间，等于截止时间也不接受。
- 每个活动每个用户仅算一个有效玩家。重复提交幂等；多局只保留最高有效分，不累计轮次得分。
- 战队分数严格汇总成员最高有效分。未加入队伍的用户可以进入个人榜和有效人数；截止前首次加入队伍时，已接受的个人最高分归入该队。
- 解锁与计分截止独立：达标后仍可计分，直到截止时间。截止后可继续试玩和保存练习记录，但不改变有效人数、个人榜和战队榜，也不能新加入队伍。
- 模拟周期为首次建立本地竞赛数据起 7 天，具体日期显示在活动及结算页。顶部控制台可关闭计分或重新开放 7 天，仅用于边界测试；重开不会自动补交旧练习记录。
- 种子用户是确定性生成的虚构数据；每个活动的战队人数与分数从这些用户计算，不再分别写死。相同分数按稳定用户 ID 排序，前端展示前 20 名与自己的最高有效分。
- 已接受成绩单独持久化，不依赖最多保留 50 局的练习历史。此前旧版本保存的成绩不自动转换为有效提交。

当前 UI 使用一个设备本地演示身份，不支持多真实账户切换、跨设备同步或反作弊。localStorage 可被修改，不能作为生产可信数据。后续后台必须复核完整轮次、身份、截止时间、提交幂等、唯一队伍和最高分聚合。

## 手动体验

1. 打开 PAPERHOOD，登录并选择队伍；浏览其他队伍时，换队按钮不可用。
2. 完成一局（至少一次买卖），在结算页保存。查看 Qualified、Accepted best 和 Team contribution。
3. 回到活动页，人数比种子基线增加 1；再玩一局保存，人数不再增加，只有更高分才增加战队分。
4. 在控制台关闭计分，再完成并保存一局：记录保留，但显示练习状态，榜单不变。
5. 在其他活动选择不同队伍，再返回 PAPERHOOD，原队伍保持不变。
